## Tsunagu v1.3.1 — 通知・メッセージ履歴・位置情報・共有ボタンの修正

- 通知が消えるように: LINE やメッセージアプリのように通知をグループでまとめるアプリでは、メッセージごとの通知を消してもアプリ自身のまとめ通知（同じ本文を持つ通知）が残っていたため、PC からは「消えない」ように見えていました。グループの最後の 1 件を消したときにまとめ通知も一緒に消すようにしました。あわせて、PC 側にまとめ通知だけが残っている場合も一覧に出るようにし、「すべて消去」も含めて確実に消えます。消せない通知（進行中・消去不可・通知へのアクセスがオフ）は、その理由を PC に表示します
- メッセージの履歴が読み込めるように: 会話の履歴を一度に全部送っていたため、長い会話で転送サイズや取得時間の問題が起きていました。新しい順に 60 件ずつ送り、PC 側で「以前のメッセージを読み込む」と古い履歴を続けて取得します。取得に失敗したときは理由（権限なし・読み取りエラー）を PC の画面に表示し、空欄のまま何も起きない状態をなくしました。読み取り時に NULL の項目があっても止まらないよう、SMS・MMS・RCS の取得を全面的に見直しました
- 「探す」が使えるように: Android 10 以降はバックグラウンドのアプリが位置情報を取得できず、これまではアプリを開いている間にしか現在地を取れませんでした。「常に許可」（ACCESS_BACKGROUND_LOCATION）の許可項目を追加し、連携サービスが動いている間は位置情報のフォアグラウンドサービスとして現在地を取得できるようにしました。位置情報が「使用中のみ」「オフ」「未許可」のどれなのかを PC の「探す」画面に表示し、そこからスマホの許可画面を開けるボタンを追加しています
- 共有ボタンが潰れないように: サイドバーの「共有」ボタンが、ナビゲーションが縦に収まらない画面の高さで縦に潰れていました（縮小を許す指定になっていたため）。アイコンと文字の大きさを固定し、どの画面幅・高さでも丸いボタンのまま表示されます

固定署名キーで署名済み。v1.3.0 以前から上書きインストールできます。

## Tsunagu v1.3.0 — USB ケーブルでつなぐ（ネットなしでも全部使える）

- USB ケーブル接続: スマホと PC を USB ケーブルでつなぐだけで、Wi-Fi・モバイル通信・インターネットがすべて使えない場所でも、通知・メッセージ・通話・写真・エクスプローラー・ファイル共有・クリップボードなど、これまでの機能をそのまま使えます。PC 側に adb のインストールは要りません（Chrome か Edge で Tsunagu のページを開くだけ）
- 仕組み: アプリが USB 用の窓口（ローカルソケット `tsunagu-usb`）を開き、PC のブラウザが USB 越しに直接その窓口と話します。通信はケーブルの中だけを通り、クラウドも Wi-Fi も経由しません
- 接続方法: スマホの「設定」→「デバイス情報」→「ビルド番号」を 7 回タップ→「開発者向けオプション」→「USB デバッグ」を ON にしてケーブルで PC とつなぎ、PC の Tsunagu（設定タブ、またはペアリング画面）で「USB で接続」を押します。スマホに出る「USB デバッグを許可しますか？」は「許可」を選びます（初回のみ）
- 速さ・安全性: 接続は USB ケーブル＞同じ Wi-Fi＞クラウドの順に優先され、ケーブルを抜くと自動でネット側へ戻ります。USB の窓口は adb（シェル）からの接続だけを受け付け、最初のやり取りでペアリング済みの鍵を確認します
- オフライン起動（Web）: 一度開いたページは、ネットがまったくない状態でも起動して USB 接続を使えます。アイコン用フォントもキャッシュするので、オフラインでもアイコンが崩れません

固定署名キーで署名済み。v1.2.0 以前から上書きインストールできます。

- 大画面レイアウト（Web）: 幅が広い PC では展開型のナビゲーションレールと複数列のホーム（端末の状態・バッテリー・再生中・クイック設定・クイック操作・最近の通知・最近の写真のカード）になり、通知と写真は一覧と詳細を左右に並べて表示します。中くらいの幅では 2 列、狭い幅では 1 列と下部ナビゲーションに自動で切り替わります

- 音量: 再生中カードにメディア音量のスライダーと「−／＋／ミュート」を追加しました。スマホ側で音量を変えても PC にすぐ反映されます
- 双方向に: スマホのアプリが接続中の PC を認識し、PC の種類・ブラウザ・OS・バッテリー（対応ブラウザのみ）・オンライン状態を表示します。スマホから PC へ、ファイル送信・クリップボード送信に加えて「PC でリンクを開く」「テキストを送る」（PC でコピーできるダイアログを表示）「PC に通知」「PC を鳴らす」（PC のタブで音を鳴らし、PC 側でも止められます）ができるようになりました。ブラウザがポップアップを止めた場合、リンクは通知やボタンから開けます。PC の音は、そのタブを一度クリックした後に鳴らせます（ブラウザの自動再生制限のため）

## Tsunagu v1.0.6 — アプリを閉じていても通知が届く（Web Push）

- 閉じていても通知: PC（Chromebook など）で Tsunagu を PWA としてインストールし、通知画面で「アプリを閉じても通知を受け取る」を有効にすると、Tsunagu を開いていない間も、スマホに届いた通知（LINE など）が PC の OS 通知として届くようになりました。仕組みは Web Push で、プッシュ用のサーバーは置かず、スマホ自身が送信者になります（VAPID 鍵はスマホ内で生成・保管され、購読情報はペアリング済み接続経由でのみ受け渡し、ペイロードは標準方式で暗号化されてプッシュサービスへ送られます）
- 二重通知の防止: PC とライブ接続中の通知は従来どおりその場で表示され、Web Push では送りません。Push で送るのは接続していないときの新しい通知だけです
- 閉じた状態での返信: Push 通知の返信欄に入力した内容は「送信待ち」として保存され、次に Tsunagu がスマホに接続した時点で自動で送信されます（保存時にその旨の通知が出ます）。通知のボタン操作も同様に接続時に実行されます
- 前提: PWA としてインストール済みで通知許可と Push が使えるブラウザ（Chromebook の Chrome、デスクトップ Chrome / Edge など）が必要です。スマホ側は Tsunagu の連携サービスが動いていてオンラインである必要があります。ペアリング解除やコード再生成をすると Push 購読も破棄されます（再ペアリング後に再度有効化してください）

固定署名キーで署名済み。v1.0.5 以前から上書きインストールできます。

## Tsunagu v1.0.5 — 既読・エクスプローラー・探す

- メッセージの既読: PC で会話を開くと、スマホ側でも既読になります（SMS/MMS の既読フラグの更新を試みます。Android の仕様上、既定の SMS アプリでないアプリからの更新は多くの端末で反映されないため、その場合はスマホ標準アプリ側の未読は残ります）。PC のスレッド一覧には未読件数バッジと太字表示が付きました。なお SMS には相手の既読を知る仕組みがなく、RCS の既読も公開 API では取得できないため、送信メッセージへの「既読」表示はありません
- ドロップ画面の修正: ファイルのドラッグをキャンセルした（ドロップせずやめた）ときに、ドロップ用画面が表示され続ける不具合を直しました
- 「スマホを鳴らす」: 右クリックまたは長押しすると、音ではなく振動で知らせます（通常クリックは従来どおり音が鳴ります）
- エクスプローラー: PC からスマホのストレージをフォルダ階層で辿り、ダウンロード・アップロード・削除・名前変更・フォルダ作成ができるタブを追加しました。「すべてのファイルへのアクセス」の許可が必要です（アプリの「連携する機能」から許可できます）
- 探す: PC で開くとスマホの現在地を OpenStreetMap の地図に表示するタブを追加しました（位置情報の許可が必要です）。この画面からもスマホを鳴らす／振動させることができます

## Tsunagu v1.0.4 — 同じネットワークで直接接続

- 接続方式: ペアリング（コード/QR）は初回だけになりました。以後は、PC とスマホが同じ Wi-Fi につながっていれば、スマホの LAN 向け受け口に PC が直接つなぎ、通信はインターネットを経由しません。同じネットワークでない場合や、ブラウザが LAN アクセスをブロックする場合は、これまでどおりクラウド経由（PeerJS）で自動的につながります。接続中は PC・スマホの両方に「同じネットワークで直接接続中」/「クラウド経由で接続中」と表示されます
- 送信したメッセージが履歴に残るように: PC から送ったメッセージは端末の送信履歴への記録を試み、あわせて Tsunagu 内にも送信記録を保持して履歴に表示します（Web 版 Tsunagu の履歴・スレッド一覧に残ります）。なお、スマホ標準のメッセージアプリの履歴に表示するには、Android の仕様上 Tsunagu を既定の SMS アプリにする必要があります
- 表記: PC 側の「SMS」ボタン・見出しを「メッセージ」に戻しました（RCS の会話は引き続き「RCSメッセージ」と表示します）

固定署名キーで署名済み。v1.0.3 以前から上書きインストールできます。

## Tsunagu v1.0.3 — リアルタイム強化と PWA 対応

- バッテリー: 残量の変化だけでなく、充電の開始・終了も PC にすぐ反映されるようになりました（接続中は自動で更新されます）
- SMS / RCS リアルタイム化: スマホに SMS・RCS が届いたり、スマホ側で送信したりすると、PC のスレッド一覧と開いている会話が自動で最新になります（再読み込み不要）
- 会話の種別表示: PC の入口ボタンを「SMS」に変更。RCS の会話には「RCS」「RCSメッセージ」、MMS の会話には「MMS」と表示されるようになりました（種別は端末内の保存形式から判定しています。なお RCS の会話への送信は、Android の制限により SMS として送信されます）
- PWA: PC のブラウザから Tsunagu をアプリとしてインストールできるようになりました（アイコンは Tsunagu のアプリアイコンです）
- ブラウザ通知: PC のブラウザ通知からスマホの通知を表示できるようになりました。LINE など返信できる通知は、対応ブラウザ（Chrome）では通知の返信欄からそのまま返信できます。対応していない環境では、通知をクリックすると Tsunagu の返信欄が開きます

固定署名キーで署名済み。v1.0.2 / v1.0.1 / v1.0.0 から上書きインストールできます。
